# Project photos

Drop photos here with these exact filenames and they will appear on the project cards automatically
(until then, each card shows a "Photo coming soon" placeholder):

| Project                                 | Filename             |
| --------------------------------------- | -------------------- |
| GeoCell – Subsurface Battery Storage    | `geocell.jpg`        |
| LiftLabs Autonomous Solar-Powered Blimp | `liftlabs-blimp.jpg` |
| Rock-Paper-Scissors Robotic Hands       | `rps-hands.jpg`      |
| Robotic Arm – Western Eng. Competition  | `robotic-arm.jpg`    |

Cards crop images to 16:9, so landscape photos work best (around 1600×900, compressed under ~300 KB).
To use a different name or format (e.g. `.png`), update the matching `src` in `index.html`.
